# Simple Interest Calculator

A beginner-friendly C program that calculates simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal** is the starting amount
- **Rate** is the annual interest rate (in percent)
- **Time** is the duration in years

## How to Run

### Compile
```bash
gcc simple_interest.c -o simple_interest
```

### Run
```bash
./simple_interest
```

## Example

```text
Enter principal amount: 10000
Enter annual interest rate (%): 5
Enter time (years): 2

Simple Interest = 1000.00
Total Amount = 11000.00
```
